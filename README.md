# Jalankan dan deploy aplikasi AI Studio Anda

Berisi semua yang Anda perlukan untuk menjalankan aplikasi ini secara lokal.

Lihat aplikasi Anda di AI Studio: https://ai.studio/apps/0607d066-3a6d-480e-a926-5a06072dbcbd

## Jalankan Secara Lokal

**Prasyarat:**  Node.js


1. Instal dependensi:
   `npm install`
2. Isi `GEMINI_API_KEY` di [.env.local](.env.local) dengan API key Gemini Anda
3. Jalankan aplikasi:
   `npm run dev`
